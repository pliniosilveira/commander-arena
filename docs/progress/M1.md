# M1 progress report: Engine core (headless)

Date: 2026-10-20. Branch `m1-engine-core`.

## What is done

- **State model** (`packages/engine/src/state/`): plain-data `GameState` with per-seat zones, object identity (new object per zone change), last-known information, the casting transaction, a resumable resolution context, the commander watch list.
- **Rules** (`src/rules/`): zone-change pipeline with replacement effects (enters tapped, enters with counters, the commander replacement CR 903.9b); casting as a snapshot transaction with cancel (A3); resolution with target re-check, fizzle and stop-and-resume for decisions; the full step and phase machine with priority passing, mana emptying and the cleanup repeat rule (CR 514.3a); state-based actions checked together; London mulligan; commander setup, tax and the command-zone choice.
- **Libraries**: seeded xoshiro128** RNG; mana cost parser and payment planner (restrictions, tiers, leftover, property-tested against a brute-force oracle).
- **AST and cards**: AST types, `validateCard` with `SUPPORTED_FEATURES` (A7), real-card fixtures for the A27 set plus clearly labelled SYNTHETIC cards.
- **API**: `createGame`, `applyAction`, `getLegalActions`, `legalActionsForDecision`, `getView`, `checkInvariants`, `stateHash`.
- **Scenario DSL** (`src/testing/`) and the required scenario tests 8, 9, 10, 12, 13, 21, 22, 24 and 29, plus mulligan, setup, target-removed-in-response, spells, Command Tower, cancel and legal-action tests.
- **AI package**: `Agent` interface with budget and injected clock, `RandomLegalAgent`, `runGame`, `replayGame`.
- **Property and hidden-information tests**: 100 complete random games, fast-check invariants after every action, replay equality, and a view audit (SPEC test 28, earlier than planned).
- **Documents**: `docs/RULES_COVERAGE.md` (new), `docs/ARCHITECTURE.md` (updated from planned to real), `AGENTS.md`, D-036 to D-039.

## Coverage numbers

None. There is no Oracle parser yet (M4 framework, M6 grammar). `docs/RULES_COVERAGE.md` lists rules by CR section.

## Known gaps

- Cards with keywords, triggers, activated abilities, modal or X spells, or a layout other than normal are unsupported; `validateCard` rejects them as supported.
- Drawing a commander from a library raises an engine error (CR 903.9b on draw); unreachable until search effects exist (M5).
- `createGame` accepts exactly two seats (M10 for more).
- Scenario test 8's haste half, "no maximum hand size", "until end of turn" effects, partial targets and mana restrictions are not testable with the M1 card set.
- Fixtures are hand-written from Oracle text and unverified against Scryfall until the spikes run or M4 imports real data.
- Average action cost is about 0.34 ms with a worst case near 5.6 ms in a 7,600-action game, around the 5 ms budget; the budgets are formally checked in M9.

## Decisions made

D-036 (M1 decision kinds, action vocabulary, Healing Salve to Angel's Mercy), D-037 (the DSL in the public API), D-038 (moved objects cease to exist), D-039 (cancel keeps the action count).

## Surprises worth remembering

- A game with 100-card decks under random play lasts about 190 turns and 7,600 actions; tests use small decks.
- Five engine bugs surfaced only when the scenario tests were written: damage could not target a player, cancel rewound the action count, the last keep dropped the first turn's events, the free-mulligan limit was off by one, and a manual payment with an invented id threw instead of returning an error.
- In this CR the Commander state-based actions are 704.6c and 704.6d, not under 704.5.
