# M4 progress report: Card data and deck import

Date: 2026-10-21. Branch `m4-card-data`.

## What is done

- **Decklist parser** (SPEC 6.1): a hand-written scanner for Arena, MTGO, Moxfield and Archidekt style lists, all section headers, set codes, collector numbers, foil markers, tags, comments, BOM, CRLF; errors carry exact line numbers; `canonicalDeck` makes every format compare equal (SPEC test 27).
- **Scryfall client** (SPEC 6.2, D-048): one shared rate-limited queue (2 requests per second for collection, named, search and random; 10 per second otherwise; 429 back-off honouring Retry-After), batching of 75 identifiers, front-face names only, matching by name, fallback to `named?exact=` then `named?fuzzy=`, a tolerant zod schema, a TTL cache interface and a memory cache, rulings and the bulk listing in the real field names.
- **Conversion and support status** (SPEC 7.1, D-052): Scryfall data to engine definitions; the parser framework with two rules; fixtures verified against real text; support reports cached per `PARSER_VERSION` (SPEC test 30).
- **Deck validation** (SPEC test 26, D-053): size, singleton with exceptions, color identity, commander eligibility, the partner family, bans, Game Changers as information.
- **Support requests** (SPEC 8.2, D-054): the schema, builder, file names and the "copy for agent" message.
- **Web app:** an import screen (paste, progress, parse errors, not-found names, close matches, commander picker, validation panel, coverage report, "Why unsupported?", request support by copy or download, saved decks, your requests with open and resolved states, play with the unsupported warning (D-055)); an import service and IndexedDB stores that fail soft; the game host plays an imported deck.

## How to try it

`pnpm dev`, "Import a deck", paste a Commander list from Moxfield, Archidekt, Arena or MTGO, Import. Check: every name resolves, the commander is found (or you are asked), the validation panel agrees with your own count, the coverage report lists what is unsupported and why, and "Play this deck" starts a game. Please report any card whose name does not resolve, any validation message that looks wrong, and any fixture the importer calls a mismatch (that means a hand-written test card differs from the real card).

## Coverage numbers

Not measured against real data. The M4 parser understands vanilla cards, keyword lines the engine can run and simple tap-for-mana abilities; the coverage report shows the real number per deck. The 60% target is for M6.

## Known gaps

- Real Scryfall responses were never seen by the new code; the schema follows what the A20 spikes observed live.
- Export-format fixtures were written from memory of each format.
- CR 903.4b (a commander that has you choose its colors) and CR 201.3 (names interchangeable with another name) are not modelled.
- The bulk file (`oracle_cards`) is not used yet; coverage tooling is M6.
- No dev-mode inbox endpoint or `pnpm card:request` CLI (M6).
