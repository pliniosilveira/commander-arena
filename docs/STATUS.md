## How to run

`pnpm install`, `pnpm dev`, open the printed address, press Start game. `?autostart=<human deck id>,<AI deck id>&seed=7` skips the menu (hidden test decks are reachable by id only); its opponent is the casual agent unless `&ai=normal` or `&ai=casual` says otherwise (D-164, D-168), while a game started from the menu or the import screen always plays the heuristic agent. Browser tests: `pnpm --filter @commander-arena/web exec playwright install chromium` (or `CHROMIUM_PATH=/opt/pw-browsers/chromium` in the cloud sandbox), then `pnpm e2e`.
